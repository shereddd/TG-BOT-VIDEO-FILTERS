# TG-BOT-VIDEO-FILTERS

# Telegram-бот для обработки видео

Бот для обработки видео с применением различных фильтров через FFmpeg.

## Возможности

1) Приём видео (как медика и как документ)
2) Применение фильтров (пока такие, но потом могут появиться и другие):
- Чёрно-белый;
- Сепия;
- Резкость;
- Размытие;
- Виньетка;
- Инверсия;
- Насыщенность;
- VHS;
- Старая плёнка;
- Контраст.

3) Отмена операции в любой момент.

## Использование
1. Отправьте боту видео;
2. Выберите фильтр из предложенных;
3. Дождитесь обработки;
4. Получите обработанное видео.
